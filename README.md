Hexon Technical Services Website
Professional Engineering & Technical Solutions for Uganda

A modern, high-conversion web platform for Hexon Technical Services Ltd. This project showcases industrial expertise in solar energy, biometric security, and electrical engineering with a focus on speed, mobile responsiveness, and SEO.

Tech Stack
Core: React 19 (Vite)

Language: TypeScript

Styling: Tailwind CSS (Dark Mode support)

Icons: Lucide React & Heroicons

Email Engine: EmailJS (Serverless Contact Form)

SEO: React Helmet Async

Key Features
Automated Lead Generation: Custom contact form with automated admin alerts and client auto-responders.

Service-Specific SEO: Dedicated metadata for Solar, CCTV, and Electrical services to improve Ugandan search rankings.

Performance Optimized: Lazy loading and optimized asset delivery via Vite.

Brand Integrity: Full Open Graph (OG) integration for professional previews on WhatsApp, LinkedIn, and Facebook.
